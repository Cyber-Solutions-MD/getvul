CVE-2024-3094
■ Critical ★ CISA KEV ⚡ exploit available

Description

Malicious code was discovered in the upstream xz-utils tarballs, starting with version 5.6.0. Through a series of complex obfuscations, the liblzma build process extracts a prebuilt object file that injects a backdoor into sshd authentication. RCE risk on systems with liblzma linked into sshd.

Remediation

Downgrade xz-utils to a version < 5.6.0. Distribution maintainers (Debian, Fedora, Arch) have already published fixed packages — confirm your package manager has the latest index, then apply system update and restart sshd. Verify with xz --version.
