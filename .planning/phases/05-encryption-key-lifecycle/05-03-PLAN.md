<objective>
Close the single blocker gap from Phase 05 UAT (Test 5, Full Key Rotation): the documented operator
command `python3 -m app.encryption rotate --new-key <key> --yes` crashes with
`sqlalchemy.exc.NoReferencedTableError: Foreign key associated with column 'audit_logs.user_id' could
not find table 'users'` and never completes.

Root cause (already diagnosed with high confidence in 05-UAT.md): `rotate_credentials()` writes an
`AuditLog` row directly (decision D-08). `AuditLog` (`app/audit.py`) has TWO foreign keys —
`user_id -> users.id` and `tenant_id -> tenants.id`. Both target tables are owned by models in
`app/tenants/models.py` (`User.__tablename__ == "users"`, `Tenant.__tablename__ == "tenants"`). When
`rotate_credentials()` runs via the standalone CLI `python -m app.encryption`, the only models imported
are `ConnectorConfig` (from `app.ticketing.models`) and `AuditLog` (from `app.audit`). Persisting
`AuditLog` triggers SQLAlchemy mapper configuration, which must resolve those FK targets; because
`app.tenants.models` was never imported, the `users`/`tenants` tables are absent from the registry and
mapper config raises `NoReferencedTableError` BEFORE any commit. `verify` and `--dry-run` do not write
an audit row, so they work — which is why the bug slipped through. The integration test
`test_audit_event` masks it because `conftest.py` eagerly imports every model at load time
(lines 44-49), so the standalone-CLI import graph is never exercised by the suite.

Purpose: PROD-05-02 (real rotation re-encrypts all connector creds in one transaction) and PROD-05-03
(the documented `python -m app.encryption rotate` invocation actually works for operators). Without
this fix the shipped rotation runbook is non-functional in the real container deployment path.

Output:
- `backend/app/encryption.py` — register `app.tenants.models` (User + Tenant) inside
  `rotate_credentials()` before the audit write.
- `backend/tests/test_encryption_rotation.py` — a subprocess regression test reproducing the real
  operator path (fails pre-fix, passes post-fix).
</objective>
