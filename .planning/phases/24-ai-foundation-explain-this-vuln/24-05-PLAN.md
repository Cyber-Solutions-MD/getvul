## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser hook -> SSE endpoint | Bearer-authenticated fetch; the response is already server-validated (Plan 04 gate) |
| validated payload -> DOM render | only schema-valid fields render; citation substring-matching adds styling only, never executes content |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-22 | Tampering (XSS) | rendering model-authored summary/business_risk/citation text | mitigate | Render as React text nodes only (no dangerouslySetInnerHTML); citation wrapping operates on matched substrings as text spans — model output is never treated as markup or instructions |
| T-24-23 | Information Disclosure | Bearer token handling in the stream hook | mitigate | Token read from localStorage same as api.ts; sent only as an Authorization header to the same-origin API; never logged |
| T-24-24 | Elevation of Privilege | Viewer triggering a paid call from the UI | mitigate | The Explain button is not rendered for Viewers (defense-in-depth); the backend require_analyst gate (Plan 04) is the authoritative control |
| T-24-25 | Information Disclosure | source_field / provenance surfaced inappropriately | accept | source_field is allowlisted grounding-field names only (e.g. cve_description) — no PII; revealed only on hover per D-14 |
