<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> POST/GET /explain-vuln | authenticated analyst/viewer request; RBAC + tenant scoping enforced here |
| Anthropic stream -> backend buffer | untrusted model output enters process memory; must pass the gate before any egress |
| backend -> browser SSE | only schema-validated, tenant-owned content crosses here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-16 | Tampering | raw model output reaching the UI | mitigate | buffer-then-validate-then-replay: get_final_message + model_validate_json + recheck before the first yield; no StreamingResponse(client...) passthrough |
| T-24-17 | Elevation of Privilege | Viewer triggering a paid call | mitigate | POST gated require_analyst; GET (read cached only) gated require_viewer — the D-17 matrix is unit-tested |
| T-24-18 | Information Disclosure | cross-tenant finding access | mitigate | get_correlated_finding is scoped by user.tenant_id; a foreign finding_id is not resolvable; cache key namespaced by tenant_id |
| T-24-19 | Information Disclosure | BYOK key in a shared client | mitigate | AsyncAnthropic constructed per-request from the decrypted key; no module singleton (AI-SPEC Pitfall 3) |
| T-24-20 | Denial of Service (cost) | runaway generation / concurrent streams | mitigate | max_tokens=1024 hard ceiling (D-07) + fail-closed budget pre-check (D-06) + inflight concurrency guard (D-25) |
| T-24-21 | Elevation of Privilege | injected instruction obeyed by the model | mitigate | Structural: prompt contract (Plan 02) delivers scanner text as data; the schema gate here is the backstop blocking off-task/leak output; injection-flagged outputs can be audited with status="injection_flagged" |
</threat_model>
