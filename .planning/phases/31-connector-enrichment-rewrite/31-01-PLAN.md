<assumption_delta_decision>
This phase promotes (not adds-alongside) two nouns:
1. The **catalog-authoritative KEV fact** becomes the single authority for the `cisa_kev`
   column across all 6 connectors (D-04). Each connector's own per-vendor KEV-ish guess
   (CrowdStrike `exploit_status>=50`, Wiz `hasCisaKevExploit`, Defender hardcoded `False`)
   **demotes to `source_signals` provenance only** — preserved, never lost, but no longer
   authoritative. This tracer proves the promotion on Defender.
2. The **generic `native_priority_score`/`native_priority_rating` pair** replaces any notion
   of per-vendor-specific exploit-signal columns (singular→plural / vendor-specific→generic).
   Rationale: each finding is single-source (`Vulnerability.source`), so one generic sortable
   pair beats 8-10 sparse vendor columns. Non-blocking.
</assumption_delta_decision>
