<objective>
RISK-09 pre/post threshold diff report + per-tenant re-tuning acknowledgment that GATES the (deferred,
human) cutover flip — a forward-looking safety artifact, NOT a live threshold retarget (34-CONTEXT
RESOLVED A5). Read every TicketRule/SavedFilter min_risk_score, compute what each stored numeric
threshold would match under the OLD Asset.risk_score vs the NEW Asset.risk_exposure_score distribution,
require an explicit audited ack, and make the admin flag-flip endpoint structurally refuse to enable
cutover unless (a) the tenant's historical backfill is complete AND (b) a FRESH ack exists. rule_engine.py
and saved_filters.py are left untouched — "helpfully" retargeting them behind the flag is Pitfall 4.

Purpose: Close the "silent reinterpretation" gap — the flip endpoint is the only path that can set the
flag True, and it cannot succeed without both gates, so no tenant's "80" can be silently reinterpreted
against a different distribution. The flip is never actually performed in this env (34-CONTEXT locked);
this plan builds + fixture-tests the machinery only.

Output: risk_cutover_service.py (diff + ack + gated enable), a dedicated admin router, main.py wiring,
two audit action strings, and the RISK-09 fixture suite.
</objective>

```python
async def compute_threshold_diff(db, tenant_id) -> dict:
    """GATE: if the tenant's RiskExposureBackfillJob.status != 'completed', return
    {'ready': False, 'reason': 'backfill_incomplete'} (Pitfall 3 — never a misleading undercount).
    Else collect every TicketRule.conditions['min_risk_score'] (>0) and every
    SavedFilter.filters['min_risk_score'] (>0) for the tenant; for each threshold compute
    old_match = count(Asset WHERE tenant_id, risk_score >= t) and new_match = count(Asset WHERE
    tenant_id, risk_exposure_score >= t). Return {'ready': True, 'items': [{source_type:'rule'|'filter',
    source_id, threshold, old_match_count, new_match_count, delta, delta_pct}], 'diff_hash': <hash>}.
    diff_hash = sha256 over the sorted-JSON items (mirror app/ai/cache.py record_hash if present, else
    hashlib.sha256(json.dumps(items, sort_keys=True).encode()).hexdigest())."""

async def record_threshold_ack(db, user) -> dict:
    """Recompute the current diff (must be ready); stamp Tenant.risk_cutover_threshold_ack_at = now and
    risk_cutover_threshold_ack_diff_hash = current diff_hash. audit(db, user, 'risk_cutover.threshold_ack',
    'tenant', str(user.tenant_id), {'diff_hash': ...}) BEFORE db.commit()."""

async def enable_cutover(db, user) -> dict:
    """BOTH GATES: (a) RiskExposureBackfillJob.status == 'completed'; (b) risk_cutover_threshold_ack_at is
    set AND risk_cutover_threshold_ack_diff_hash == the CURRENT diff_hash (stale ack after a threshold
    change fails). If either fails raise HTTPException(status_code=409, detail=<which gate>). Else set
    Tenant.cutover_risk_exposure_scoring = True; audit(db, user, 'risk_cutover.flag_enable', 'tenant',
    str(user.tenant_id), {...}) BEFORE db.commit(). NOTE: never actually called against live data here."""
```
