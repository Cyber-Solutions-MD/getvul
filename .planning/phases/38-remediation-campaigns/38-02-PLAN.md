<objective>
Deliver CAMP-02: bulk-create/assign tickets for a campaign, one ticket per owner, reusing the
existing owner routing and dedup-by-URL logic verbatim. This re-carves `create_remediation_ticket()`
(which today makes ONE ticket for the whole group) into a per-owner loop — the single largest net-new
code surface in the phase (38-RESEARCH.md Pattern 4). Every run is audited (D-10); already-ticketed
findings are adopted, not duplicated (D-06); owner-less findings land unassigned in the default
project (D-08); campaign tickets use the bare `remediation_id` as `created_by_rule` to close the
rule-engine double-ticket gap (D-20 / Pitfall 1).

Purpose: turn a persisted campaign into assigned work respecting existing routing.
Output: `bulk_create_campaign_tickets` service + `POST /{id}/bulk-assign` + tests.
</objective>
