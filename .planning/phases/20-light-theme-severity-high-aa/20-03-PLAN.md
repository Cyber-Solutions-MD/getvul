<false-green-guard>
CRITICAL — the verify command MUST gate on Playwright's real exit code, not merely on log contents.
A `;` between the `tee` pipeline and the grep logic severs the exit code, so a run that crashes,
times out, or errors mid-sweep (server down, uncaught exception) could STILL print a green token if the
log happens to contain the describe name and no `[serious]`/`[critical]` string was ever logged. That
is the exact false-green this phase exists to close. Gate on `PIPESTATUS[0]` (Playwright exits non-zero
if ANY test/describe fails OR the run errors) AND require the last route name in the log.
</false-green-guard>
