<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| tenant admin/owner -> settings API | policy + secrets are user-controlled input |
| DB at rest | channel secrets stored in Tenant.sla_config JSONB |
| API -> browser | settings GET must not leak secrets |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-36-sec-atrest | Information Disclosure | channel secrets in sla_config | mitigate (HIGH) | Fernet encrypt_value at rest (D-14); goes beyond the pre-existing plaintext smtp_config precedent (Pitfall 9) |
| T-36-sec-readback | Information Disclosure | GET /settings round-trip | mitigate (HIGH) | mask-on-read (_safe_sla) + keep-on-masked-write; browser never sees plaintext |
| T-36-sec-rbac | Elevation of Privilege | policy edit by non-owner | mitigate | require_admin (GET) / require_owner (PATCH) preserved (D-10) |
| T-36-sec-ssrf-pre | Tampering | storing an internal webhook URL | mitigate | https-only validation at save time (defense-in-depth with Plan 02 send-time SSRF guard) |
| T-36-sec-audit | Repudiation | policy change without audit | mitigate | fail-closed audit("sla.policy_update") before commit |
</threat_model>
