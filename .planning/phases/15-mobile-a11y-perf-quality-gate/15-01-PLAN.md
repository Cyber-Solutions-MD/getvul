| captured state → git | The JWT and any session token land in e2e/.auth/state.json on disk |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-15-02 | Information Disclosure | Test credentials `admin@getvul.local` / `Admin123!` in setup.ts | accept | Test-only default admin created by backend/create_admin.py for local dev; not a production credential. Credentials read from `process.env.E2E_EMAIL`/`E2E_PASSWORD` first so CI can override without editing source. Documented as test-only in a code comment; not surfaced into committed reports. |
| T-15-03 | Information Disclosure | Playwright HTML report / trace (may embed cookies/tokens) | mitigate | Task 2 gitignores `test-results/`, `playwright-report/`, `blob-report/` so traces with auth state are never committed |
</threat_model>
