  <action>
    Create `frontend/scripts/check-bundle-all.mjs` (ES module, Node). It must:
      - Read `next build` output: if stdin is piped use it; otherwise run `execSync('npx next build', { encoding:'utf-8', stdio:['ignore','pipe','inherit'] })` (same pattern as check-bundle.mjs).
      - Strip ANSI (`stripAnsi`), split into lines, and find EVERY route line: a line whose route token starts with `/` (matches `/`, `/login`, `/dashboard`, `/dashboard/...`, including `/dashboard/assets/[id]`). For each, extract the LAST `(?<![A-Za-z])(\d+(?:\.\d+)?)\s*(kB|MB|B)\b` token as First Load JS, convert to bytes with the 1024 multiplier.
      - Set `const MAX_KB = 250;` and `const MAX_BYTES = MAX_KB * 1024;`. For each route, compare bytes <= MAX_BYTES. Print a per-route `PASS|FAIL  <route>  <kB>` line. Collect failures.
      - Exit 0 if all routes within budget; exit 1 if ANY route exceeds 250 KB; exit 2 on build failure OR if zero route lines parsed (defensive — a parse miss must NOT silently pass).
      - Print a summary footer: total routes checked, the max route + its size, and the budget.
    This is a CONFIG/SCRIPT file (no JSX). The exit-code behavior IS the contract: it MUST exit non-zero when a route exceeds budget AND when zero routes parse.
  </action>
  <verify>
    <automated>cd frontend && node -c scripts/check-bundle-all.mjs && grep -q "250" scripts/check-bundle-all.mjs && printf 'Route (app)  Size  First Load JS\n+ / 1 kB 999 kB\n+ /login 2 kB 100 kB\n' | node scripts/check-bundle-all.mjs; test $? -eq 1 && echo OVER_BUDGET_FAILS_OK; printf 'Route (app)  Size  First Load JS\n+ / 1 kB 120 kB\n+ /login 2 kB 100 kB\n' | node scripts/check-bundle-all.mjs; test $? -eq 0 && echo UNDER_BUDGET_PASSES_OK; printf '' | node scripts/check-bundle-all.mjs; test $? -eq 2 && echo EMPTY_EXITS_2_OK</automated>
  </verify>
  <acceptance_criteria>

    - Piping a build-output fixture with a 999 kB route makes the script exit 1 (OVER_BUDGET_FAILS_OK printed)
    - Piping a fixture where all routes are under 250 kB makes the script exit 0 (UNDER_BUDGET_PASSES_OK printed)
    - Piping empty input exits 2 (EMPTY_EXITS_2_OK printed) — defensive, does not silently pass
  </acceptance_criteria>
