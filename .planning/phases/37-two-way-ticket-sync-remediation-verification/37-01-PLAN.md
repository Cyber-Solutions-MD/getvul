```python
async def mark_vulnerability_remediated(db: AsyncSession, vuln: Vulnerability) -> RemediationEvent:
    now = datetime.now(UTC)
    vuln.status = "REMEDIATED"
    vuln.remediated_at = now
    tier = _freeze_tier_at_remediation(vuln)
    duration_seconds = int((now - vuln.first_detected_at).total_seconds())
    event = RemediationEvent(tenant_id=vuln.tenant_id, vulnerability_id=vuln.id,
                             tier_at_remediation=tier, duration_seconds=duration_seconds,
                             first_detected_at=vuln.first_detected_at, remediated_at=now)
    db.add(event)               # no flush/commit — caller owns the txn boundary
    return event
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scanner connector → run_sync | Untrusted connector sync OUTCOME (SUCCESS vs FAILED) governs whether the sweep may close findings |
| scheduler → AuditLog / Vulnerability writes | No `CurrentUser`; system-actor rows must still carry the real tenant_id |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37-01 | Denial (of accurate state) | run_sync absent-sweep | mitigate | Sweep runs ONLY in the SUCCESS branch; a FAILED/partial sync (auth failure, raised exception) never advances a streak — an attacker/outage inducing sync failure cannot false-close findings (D-02) |
| T-37-02 | Information Disclosure | system-actor AuditLog | mitigate | Construct AuditLog directly with `tenant_id=vuln.tenant_id`; never `app.audit.audit(user=None)` which stamps a nil UUID and cross-orphans the row (Pitfall 4) |
| T-37-03 | Tampering | streak counter | mitigate | Sweep query is scoped to the connector's own `tenant_id` + `source`; findings of other tenants/sources are untouched |
| T-37-04 | Repudiation | auto-close decision | mitigate | Every rescan-verified close writes an AuditLog with streak + source in details and a durable RemediationEvent (MTTR) — the decision is fully traceable |
</threat_model>
