|----------|-------------|
| client role → reachable settings categories | useAuth().role gates which panes/endpoints are reachable (UX layer) |
| client → PATCH /tenant/settings, /tenant/users | settings + account mutations cross to the backend (Owner-gated) |

| audit log → AuditLogPane | tenant audit rows must not expose cross-tenant data |
