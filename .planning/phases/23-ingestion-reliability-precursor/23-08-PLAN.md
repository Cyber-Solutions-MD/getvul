| Analyst-selected provider → create mutation | Client passes a provider string that the backend re-validates (enum) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-22 | Information Disclosure | provider list rendering | mitigate | The picker only renders what the tenant-scoped endpoint returns; no client-side global provider list. Server enforces scoping (Plan 04 T-23-10) |
| T-23-23 | Input Validation | client-chosen provider | mitigate | Backend re-coerces via `TicketProvider(...)` (Plan 04 T-23-12); the client is not the trust anchor |
| T-23-24 | (UX safety) | creating against an unconfigured provider | mitigate | Create action disabled when the endpoint returns no configured providers; empty state deep-links to Connectors instead of allowing a doomed create |
