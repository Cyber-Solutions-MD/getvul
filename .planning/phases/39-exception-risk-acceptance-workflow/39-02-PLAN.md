| Boundary | Description |
|----------|-------------|
| Browser → grant endpoint | Client supplies scope_type, target IDs, cve_id, expiry — all untrusted |
| Tenant A ↔ Tenant B | asset_id / asset_group_id / cve_id resolution must be tenant-scoped |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-39-07 | Tampering | ASSET/ASSET_GROUP scope resolution | mitigate | asset_id/asset_group_id resolved against tenant-scoped tables; 404 (not 403) on a cross-tenant miss |
| T-39-08 | Tampering (governance bypass) | grant FINDING scope | mitigate | cve_id/asset_id derived server-side from the resolved Vulnerability (Pitfall 9) — client cve_id ignored for FINDING |
| T-39-09 | Tampering / Repudiation | expires_at hard cap | mitigate | validate_expiry future-only + 365d cap, server-authoritative; a 2099 date is rejected regardless of client attrs (D-14) |
| T-39-10 | Tampering (over-broad silence) | scope semantics | mitigate | every scope stays CVE-pinned (D-10); no whole-asset blanket branch exists in active_exception_subquery |
</threat_model>
