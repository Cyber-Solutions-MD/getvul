<objective>
Lay the Phase 13 database foundation: three Alembic migrations (026 ticket_comments, 027 ticket.blocked + blocked_reason + sla_due_at + backfill + index, 028 ticket_watchers) chained off current head `025_add_asset_tags`, the matching SQLAlchemy ORM models, and the Pydantic request schemas with Phase-12 BL-01 validators.

**Canonical ticket identity (Open Question O1 — RESOLVED, carry into every downstream plan):** The `Ticket` model is one row per (vulnerability_id, provider). A logical ticket = the group of rows sharing one `external_ticket_url`, exactly as `list_tickets` already groups (it returns `id = first_ticket_id`, the MIN row id in the group). Per researcher A3 and Open Question O1 recommendation: **comments and watchers FK to `tickets(id)` using `first_ticket_id` (the deterministic MIN id of the `external_ticket_url` group)**; blocked/sla apply to the WHOLE group (`WHERE external_ticket_url = ...`), mirroring how `close_ticket` already operates. This plan only creates the schema; the group-resolution logic lives in Plan 03. The FKs reference `tickets(id)` with `ondelete="CASCADE"` so any row deletion is safe; downstream code always resolves the canonical `first_ticket_id` before writing.

Purpose: Frontend hooks (Plans 07/08) and the service/router layer (Plan 03) depend on these tables and schemas existing.
Output: 3 migration files, extended models.py, extended schemas.py, a migration round-trip test.

```python
def upgrade():
    op.add_column("tickets", sa.Column("blocked", sa.Boolean, nullable=False,
                  server_default=sa.text("false")))
    op.add_column("tickets", sa.Column("blocked_reason", sa.Text, nullable=True))
    op.add_column("tickets", sa.Column("sla_due_at", sa.DateTime(timezone=True), nullable=True))
    # D-SLA-03 backfill: each ticket ROW is 1:1 with its vuln (vulnerability_id FK),
    # so per-row value = that vuln's sla_due_at. The group MIN (per external_ticket_url)
    # is then computed at read time in list_tickets (Plan 03).
    op.execute("""
        UPDATE tickets t
        SET sla_due_at = v.sla_due_at
        FROM vulnerabilities v
        WHERE t.vulnerability_id = v.id
          AND v.sla_due_at IS NOT NULL
    """)
    op.create_index("ix_tickets_tenant_sla", "tickets", ["tenant_id", "sla_due_at"])

def downgrade():
    op.drop_index("ix_tickets_tenant_sla", table_name="tickets")
    op.drop_column("tickets", "sla_due_at")
    op.drop_column("tickets", "blocked_reason")
    op.drop_column("tickets", "blocked")
```
