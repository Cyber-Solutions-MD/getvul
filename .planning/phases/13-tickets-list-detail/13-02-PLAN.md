2. `class JiraClient:` constructor `__init__(self, email: str, api_token: str, base_url: str)`:
   - Build `self._client = httpx.AsyncClient(base_url=base_url, timeout=30, auth=httpx.BasicAuth(email, api_token), headers={"Accept": "application/json", "Content-Type": "application/json"})`. Jira Cloud uses Basic auth `email:api_token` per CITED docs. NEVER log `api_token`.
3. `async def test_connection(self) -> dict:` — `GET /rest/api/3/myself`; return `{"success": True, "message": "...", "account_id": ...}` on 200, `{"success": False, "message": ...}` on failure. Match asana_client's return shape.
4. `async def create_ticket(self, project_key: str, summary: str, description: str, assignee_account_id: str | None = None) -> JiraIssue | None:` — `POST /rest/api/3/issue` with body `{"fields": {"project": {"key": project_key}, "summary": summary, "issuetype": {"name": "Task"}, "description": <ADF doc>}}`. v3 requires Atlassian Document Format (ADF) for description — wrap plain text as `{"type":"doc","version":1,"content":[{"type":"paragraph","content":[{"type":"text","text": description}]}]}`. On 201 read `{id, key}` and construct `url = f"{base_url.rstrip('/')}/browse/{key}"`. Return `JiraIssue`. On failure log via structlog (NO token) and return None.
5. `async def get_issue(self, issue_id_or_key: str) -> dict | None:` — `GET /rest/api/3/issue/{issue_id_or_key}`; return raw dict (caller reads `fields.status.name` for external_status). None on failure.
6. 429 handling: mirror asana_client — on HTTP 429 read `Retry-After`, sleep, retry once.
7. `async def close(self) -> None:` calls `await self._client.aclose()`.

Out of scope (do NOT implement, per D-PROV-02): add_comment, list_projects, update_issue, bulk sync, watchers fetch.
