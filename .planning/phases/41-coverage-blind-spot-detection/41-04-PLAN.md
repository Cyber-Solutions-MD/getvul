|----------|-------------|

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-41-10 | Elevation of Privilege | POST /route-to-owner | mitigate | require_analyst gate (analyst+); viewer 403; asymmetric with the require_viewer GETs (D-08) |
| T-41-11 | Information Disclosure | _get_asset_or_404 on the POST | mitigate | tenant_id in the WHERE clause; cross-tenant asset_id → 404 not 403/500 (IDOR) |
| T-41-12 | Repudiation | route-to-owner audit | mitigate | fail-closed audit() with who/what/routed_to, audit-then-commit so any audit failure aborts the write (D-08) |
| T-41-13 | Tampering (SSRF) | tenant alert-channel push (D-09) | mitigate | dispatch_channel reuses the existing _validate_webhook_url SSRF guard — never a hand-rolled outbound POST |
| T-41-14 | Denial of Service (notification abuse via repeated calls) | repeatable notify action | accept | repeatable by design (no state transition); every call audited so abuse is attributable; analyst-gated limits the actor set |
</threat_model>
