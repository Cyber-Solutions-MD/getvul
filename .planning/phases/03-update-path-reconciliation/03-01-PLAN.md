<objective>
Hard-remove the auto-update cron mechanism everywhere it is provisioned or documented (except the CD-owned files, which Plan 03-02 handles). This makes the deploy race structurally impossible: there is no code path left that installs `/usr/local/bin/getvul-update` or the `/etc/cron.d/getvul-update` cron.

Purpose: Per D-01, release-triggered GitHub Actions CD is the single canonical update path. Per D-02, the cron is removed with no opt-in flag and no dormant code. Per D-03, every reference to the deleted `getvul-update` command is cleaned up so nothing points at it.

Output: `install.sh`, all three `infra/{gcp,aws,azure}/startup.sh` scripts, all three `main.tf` comments, and the cron-only doc surfaces (`docs/02-architecture.md`, `docs/07-project-structure.md`, `docs/17-troubleshooting.md`, `docs/01-overview.md`) no longer install or reference the cron. `scripts/auto-update.sh` is deleted from the git tree.
</objective>
