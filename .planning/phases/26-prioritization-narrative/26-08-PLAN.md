<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Submitted batch (pre-restart) → poller (post-restart) | In-flight batches must be re-findable from Postgres, not lost with the process |
| Batch result → tenant cache | A result must be written under the owning tenant's key only, using the frozen model/prompt_version it was submitted with |
| Nightly/poll dispatch → connector-sync tick | Batch work must never block the scheduler tick (D-05 hard constraint) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-12 | Denial of Service (tick stall) | scheduler blocks A + B | mitigate | BOTH `run_batch_prewarm()` and `poll_pending_batches()` are dispatched via `asyncio.create_task`, never an inline `await` (Pitfall 3 — the poller is the easy one to get wrong). The non-blocking test asserts the block returns before a slow fake finishes; the grep gate proves zero inline awaits. |
| T-26-08 | Denial of Service (orphaned spend) | `poll_pending_batches()` resume | mitigate | The poller SELECTs `AiBatchJob WHERE status='in_progress'` from Postgres every call, so a batch submitted before a restart is still retrieved — the durability of Plan 06's table is realized here. Test seeds an in_progress row directly and asserts it is completed. |
| T-26-03 | Information Disclosure (cross-tenant cache) | poller cache write | mitigate | The cache key is built from the AiBatchJob row's own `tenant_id` (one batch = one tenant, set at submit) + `custom_id_hash_map[custom_id]` — a result can never be attributed to a different tenant than the batch it came from; the frozen model/prompt_version guarantee the analyst's GET finds it (D-06). |
| T-26-04 | Tampering (accounted-spend accuracy) | poller → `validate_and_cache_batch_result()` | mitigate | The poller books cost only through Plan 07's validator, which applies the ×0.5 discount; errored/canceled/expired are audited at cost 0.0 (never billed) and never cached. |
</threat_model>
