<assumption_delta_decision>
This phase is a singular→plural generalization: hardcoded 4-source FK columns → a general source-set covering all 6 VulnSource values (forward-compatible with a 7th).

- **Now-primary noun:** the **source-set** — `sources ARRAY(String)`, stored in canonical form (deduped `VulnSource.value` strings, sorted by enum declaration order), as the canonical identity of "which scanners see this finding." It drives both `sources_count` and the resolved source-name list.
- **Decision:** **promote**. The general `sources` array is promoted to canonical/primary; the 4 per-source FK columns are demoted and removed (D-01/D-03). This is not add-alongside — the old columns are dropped, not kept in parallel.
- **Rationale:** one source of truth makes `sources_count` and the source-name list structurally unable to disagree (CORR-03) and adds a 7th source with zero schema change.
- **Suggested invariant test:** `sources_count == len(sources)` for every correlation row across every source combination (1-of-6 through 6-of-6) — authored as a standing regression in Plan 02.
</assumption_delta_decision>
