# Milestone v2.0: UI/UX Redesign

**Status:** ✅ SHIPPED 2026-06-30
**Phases:** 9–15
**Total Plans:** 49 (all complete)

## Overview

Replaced v1's `!important`-hack light theme and missing-primitives frontend with a Wiz-inspired sunset-palette redesign across every authenticated screen. Each phase shipped one screen end-to-end (tokens + primitives + page wired to the real backend + state patterns + a11y + tests) as a vertical slice. No foundation-only phase — UX-F-01..F-04 rode inside Phase 9 (the `/login` slice), a deliberate guard against the rolled-back v2-01 attempt that shipped foundation without a visible screen.

**Design contract:** `.claude/skills/sketch-findings-getvul/` (43 validated decisions across 7 reference files), sourced from a 6-sketch exploration on 2026-05-12.
**Requirements:** see `v2.0-REQUIREMENTS.md` (50 items: UX-01..07 + cross-cutting UX-S-* + embedded UX-F-*).

## Milestone Summary

**Quality gate (verified on the production build, live backend):**
- Playwright suite: 28 passed / 2 skipped (Firefox theme — unreliable colorScheme emulation, covered on Chromium+WebKit) / 0 failed — no horizontal scroll at 360/390/768/1280, zero critical/serious axe WCAG 2.1 AA per route, cross-browser smoke, theme, reduced-motion, focus-not-obscured.
- Bundle budget: 15/15 routes ≤ 250 KB gzipped (largest /dashboard/tickets 166 KB).
- Lighthouse mobile: /login 97 perf / 95 a11y; /dashboard 90 perf / 95 a11y.
- 676 frontend unit tests + `npm run lint` (0 jsx-a11y errors) green.

**Milestone audit (`v2.0-MILESTONE-AUDIT.md`):** `tech_debt` — 0 blockers, 48/48 requirements wired, all E2E flows working. The one user-facing warning (CSPM finding drill lacked a mobile bottom sheet) was fixed before completion.

**Key decisions:**
- Sunset palette is dark-first; light theme is architecture-only (full light-mode visual QA deferred to UX-D-03).
- State primitives (Phase 11) are the single source consumed by all later list screens — no per-screen re-implementation.
- DrillPanel generalized additively (idKey/renderContent) for vuln/ticket/asset/finding callers; back-compat `cveId` alias retained.
- `(authed)` route group is the single chrome owner; `force-dynamic` (authed routes are client-rendered behind useAuth).

**Tech debt carried forward (logged to backlog, non-blocking):**
- Legacy-route client navigation (`/assets/:id`, `/assets`, `/tickets`) 308-redirects to `/dashboard/*` instead of using canonical hrefs.
- Dead middleware redirect `/integrations` → `/dashboard/integrations` (no such page; route renamed to `/connectors`).
- `useDocumentTitle` absent from 5 pages (assets/[id], cspm, connectors, users, settings) — generic tab title.
- Dark-theme contrast DESIGN-SYSTEM GAPS: app-layer overrides of `--color-text-faint` and accent-on-soft badge text — reconcile into sketch-findings foundation.md / visual-language.md.
- Nyquist validation PARTIAL on phases 9, 10, 11, 14, 15 (requirements functionally verified; test-coverage formalization incomplete).

**Pending human (non-blocking):** Safari.app severity-glyph 14px legibility spot-check (D-02; WebKit-in-Playwright covers presence/axe).
